Acme vendor onboarding

Every path for the walkthrough. The companies are fictional. The vendor pages are mocked. No Grok API call is built.

Pages

Path What it opens
/deck/ The walkthrough. Intake, a research pack, then approval routing.
/dataset/ The three requester messages to paste into the bot.
/ops/ The ledger. What was automated, and what still needs a person.
/approval/ The decision page. It needs a case id on the path.
/api-literacy/ Where a Grok API call would enter. The call itself is not built.
